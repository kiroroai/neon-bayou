# Neon Bayou

Neon Bayou is an open-world crime game set in Cypress Bay, a fictional sun-soaked city on the edge of a dark bayou. You play Rook, a driver fresh back in town with $250 and a reputation to rebuild: steal cars, run three story missions for Delacroix and Mama Odette, dodge the Cypress Bay police as your wanted stars climb, and make the city yours — on foot or behind the wheel, by day or under the neon.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network: the game is plain static files under `game/`, with three.js vendored locally.
